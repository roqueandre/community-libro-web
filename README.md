# Comu-Libro 📚

Sistema de gestão para bibliotecas comunitárias, desenvolvido como parte de uma atividade extensionista do curso de Análise e Desenvolvimento de Sistemas.

O objetivo principal deste projeto é modernizar o funcionamento de bibliotecas comunitárias, substituindo controles manuais por uma solução automatizada, gratuita e de código aberto que possa ser facilmente replicada.
